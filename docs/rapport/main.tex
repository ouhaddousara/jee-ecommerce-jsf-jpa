\chapter*{Résumé}
\addcontentsline{toc}{chapter}{Résumé}
Ce rapport présente la deuxième version d'« Atlas Boutique », l'application de commerce électronique de
l'atelier~2, dont la couche web est entièrement réécrite avec \textbf{JavaServer Faces 2.2} (Mojarra) et des
pages \textbf{Facelets}. Les entités JPA, les services, l'injection CDI et la sécurité sont conservés ; les
servlets et les pages JSP sont remplacés par six beans CDI, un par « gestion » (connexion, inscription,
vitrine, panier, produits, catégories), et par seize pages \texttt{.xhtml} bâties sur un gabarit et cinq
composants composites.

Le document explique les décisions plutôt que le code : pourquoi garder les services de l'atelier~2,
comment le cycle de vie JSF s'accorde avec le motif Post/Redirect/Get, comment concilier les composants JSF
avec une politique de sécurité du contenu stricte (\texttt{script-src 'self'}), et comment déplacer les
règles d'affichage dans Java pour contenter les analyseurs d'expressions EL. Un incident d'exécution
(classe \texttt{javax.xml.bind.DatatypeConverter} absente sous Java 17) est détaillé. L'ensemble est vérifié
par \nbChecks{} contrôles automatisés et un parcours manuel de quinze scénarios.

\textbf{Mots-clés :} Java EE, JSF, Facelets, CDI, Weld, JPA, EclipseLink, MySQL, Tomcat, sécurité web.
